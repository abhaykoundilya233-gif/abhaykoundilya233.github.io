PRIVATE CONTENT MANAGEMENT

Manage the archive.

Article writing and publishing are managed securely through Pages CMS using the GitHub account that has permission to edit this website's repository.

Open Pages CMS ↗
  1. Sign in to Pages CMS with the GitHub account that owns this website.
  2. Allow Pages CMS to access this repository when prompted.
  3. Open Research articles to create or edit an article.
  4. Set its status to published when it is ready for readers.

Only people with write access to the GitHub repository can change the website's content. Do not share your GitHub password or give repository write access to people you do not trust.
